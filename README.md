# Casualties-Unknown-RUS-Translation-
Любительский перевод игры Casualties: Unknown на русский язык. ЕЩЕ В РАЗРАБОТКЕ!! (если это хоть кто-то будет качать)

Инструкция по установке.
1. Качаете файлик "RU_v1.0.json"
2. Заходите в папку с игрой через стим (Управление → Локальные файлы) и кидаете его по пути: ...\Casualties Unknown\CasualtiesUnknown_Data\Lang\
3. Заходите в игру → Settings (Настройки) → Русский (RU_v1.0)
4. Готово, наслаждайтесь игрой!
