# Casualties: Unknown (RUS-Translation) (В РАЗРАБОТКЕ!)
Любительский перевод игры Casualties: Unknown на русский язык. ЕЩЕ В РАЗРАБОТКЕ!! (если это хоть кто-то будет качать)
Качайте, если прям не терпится поиграть в игру и вам плевать на недоделанный перевод.

Инструкция по установке.
1. Качаете файлик "RU_v1.X.zip"
2. Распаковываете его
3. Заходите в папку с игрой через стим (Управление → Локальные файлы) и кидаете RU_v1.X.JSON по пути: ...\Casualties Unknown\CasualtiesUnknown_Data\Lang\
4. Заходите в игру → Settings (Настройки) → Русский (RU_v1.X)
5. Готово, наслаждайтесь игрой!
